# curso-basico-codex-hashtag

Projeto prático inicial explorando conceitos básicos de HTML, CSS e JavaScript.

## 📌 Objetivo

Este projeto foi desenvolvido como parte de estudos práticos para consolidar os fundamentos do desenvolvimento web front-end, abordando a estruturação semântica, estilização moderna e interatividade dinâmica.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página.
- **CSS3**: Estilização visual, layout e responsividade.
- **JavaScript**: Lógica e dinamismo dos componentes interativos.

## 💻 Como Visualizar

Para rodar e visualizar o projeto localmente:

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo `index.html` ou abra-o diretamente no navegador de sua preferência (Chrome, Edge, Firefox, etc.).
   - *Opcional:* Se você utiliza o Visual Studio Code, pode utilizar a extensão **Live Server** para rodar com recarregamento automático.
